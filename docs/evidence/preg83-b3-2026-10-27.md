## Commands and outcomes

With the exact toolchain and common environment above:

```sh
CGO_ENABLED=0 go test -json -count=1 \
  -run '^TestPreg83(Compiler|CLI|Local|GeneratedDisabled)' \
  ./internal/codegen ./cmd/gohp ./runtime ./tests
CGO_ENABLED=0 go vet ./internal/frontend ./internal/semantic ./internal/codegen ./runtime ./cmd/gohp ./tests

  CGO_ENABLED=1 go test -json -tags gohp_pcre2 -count=1 \
  -run '^TestPreg83GeneratedNativeComparison$' ./tests
```

Default seven tests PASS once; vet exit 0 with empty output. Default generated
CGO0 execution explicitly panics for the unavailable backend before subsequent
PHP statements execute. Compiler/profile/CLI tests prove admission and rejection,
not a linked native backend. Gofmt and diff whitespace checks are clean.

Native setup attempts are retained, not relabeled PASS:

1. c7221f3: generated build/host checks completed, but Docker was absent from the
   restricted PATH. No PHP oracle executed. Overall comparison FAIL.
2. Same code, Docker PATH fixed: PHP exited 255 before comparison because its
   initial LC_CTYPE was `C.UTF-8`, not the observer's required `C`. Overall FAIL.
   A read-only PHP configuration probe confirmed version, PCRE, locale and limits.
3. c07d569: observer explicitly selects C locale, as the earlier B2 fixture did.
   Actual generated Go versus fresh PHP comparison PASS (1.43 seconds).

The successful native run has **11 ordered typed observations**: basic match,
no-match, named/trailing unmatched captures, negative offset, middle unmatched
capture with typed parameters/array return, capture copy then local mutation,
NUL bytes, UTF-8 byte offset, lookahead plus possessive repetition, actual
backtracking-limit false/error 2, and a shared-state sequence through generated
functions/arrows/methods followed by a no-match reset. Host-side generated ABI
assertions additionally interleave two executions, check failure-to-success reset
and fresh standalone wrappers. These ABI assertions are not a PHP Fiber oracle.

Observers preserve types, raw string bytes (base64), array insertion order and
key types. Comparison is structural JSON equality, **not** equal serialized JSON
bytes: serializer object-key order, slash escaping and trailing newline differ.
The PHP failure row is explicitly required to be bool false/error 2, not merely
equal to Go. No B1/B2 tests were rerun and no successful comparison was repeated.
