## Implementation and next-key state

The frontend admits exactly one address and normalizes case. Semantic checks
reject undefined/reserved roots, known non-arrays, hidden IR/call metadata,
unsupported address/result shapes and generic call bypasses before output.
Generated code uses only the guarded legacy map lane. The optional result is
unknown/mixed, not an inferred class or fixed scalar. Loop/switch widening
tracks both local target and result. A result/target alias publishes last.

ArrayPopLocal and NestedProperty.Pop detach the remaining/returned arrays and
publish once only for nonempty inputs; property owner/name resolution precedes
the operation. Full structural PropertyObject hosts explicitly opt in to the
existing ABI; this is not an unforgeable provenance or authorization boundary.
Unknown actual non-arrays and invalid object/slot domains reject explicitly.

The shared Index retains a next key independently from maximum-key occupancy.
Only a removed integer predecessor rewinds it; string keys do not. Popping
MAX frees that same saturated key. Popping MAX-1 after MAX makes the lower
key available while MAX remains occupied; the subsequent MAX append must
reject, not silently replace it. Minimum-int rewind restores PHP's sentinel
and automatic0. No state is reconstructed from the remaining entries and no
general deletion API is introduced. Copies retain this state.
